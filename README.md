Если вы точно понимаете настройки исключений, предпочтительно исключить каталог; в противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите Безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * В Windows 11 Secure DNS можно включить непосредственно в параметрах системы - [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это рекомендуемый вариант
    * На роутерах Keenetic активируйте параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/webpaladinbless/zapret-discord-youtube/releases/latest)

3. Откройте свойства скачанного архива и включите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы

5. Запустите необходимый файл
    * Для поиска подходящей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления стратегии в автозапуск выберите **`service.bat`** -> `Install Service` -> *нужная стратегия*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую для себя**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавляет выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** - удаляет стратегию и WinDivert из служб
  - **`Check Status`** - показывает состояние обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** - меняет режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - переключает фильтрацию сервисов из `ipset-all.txt`.  
  Этот режим полезен при проверке ресурса, который без zapret работает, а с ним перестаёт открываться.  
  В скобках показывается текущий статус:
    - `none` - ни один IP не проверяется
    - `loaded` - IP сопоставляются со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включает или выключает автоматическую проверку обновлений
  - **`Replace active fakes`** - заменяет используемый fake на другой из каталога `bin`
  - **`Update IPSet List`** - загружает актуальную версию `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновляет hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - вручную проверяет наличие обновлений
  - **`Run Diagnostics`** - ищет распространённые причины неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапной потери работоспособности
  - **`Run Tests`** - запускает проверку стратегий:
    - `Standard tests` - тестирует сайты из `utils/targets.txt`
    - `DPI checkers` - проверяет DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/webpaladinbless/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - Запустите текстовый редактор от имени администратора и откройте файл `hosts` в созданной папке
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленные аналогичные строки
  - Сохраните файл и повторите подключение. Если результата нет, проверьте, что `hosts` действительно был сохранён.

#### Работа функции не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/webpaladinbless/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Обнаружение конкретной стратегии может произойти не сразу, поэтому рабочий вариант иногда перестаёт помогать спустя некоторое время.
> В этом репозитории собрано много стратегий обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не показывает ошибок

- Проверьте, внесён ли адрес ресурса в списки доменов или IP

- Проверьте другие варианты, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/webpaladinbless/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и другие данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; устраните найденные ошибки и в конце ответьте Y
- Удалите каталог zapret
- Скачайте свежую версию `zapret-discord-youtube-...` со [страницы релизов](https://github.com/webpaladinbless/zapret-discord-youtube/releases)
- Щёлкните по архиву правой кнопкой мыши, откройте свойства и при наличии нажмите "Разблокировать" -> "Применить" -> "ОК"
- Распакуйте архив в новый каталог в корне диска; путь не должен содержать пробелы и специальные символы
- Запускайте разные скрипты `general` и проверяйте нужные ресурсы. Если доступ не появился, закройте программу через значок замка на панели задач и выберите другую стратегию
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service`

### Не работает игра/приложение с включённым запретом

- Проверьте в service.bat, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы командой в Windows Command Prompt (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ним бороться.
- Попробуйте все остальные стратегии, особенно если раньше доступ работал.
- См. также [#251](https://github.com/webpaladinbless/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается сайт YouTube, и запустить её
- В `service.bat` перейдите в `Run Diagnostics` и очистите кэш Discord
- Проверьте приложение Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей
- Если браузерная версия также недоступна, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/webpaladinbless/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Установите и используйте [tg-ws-proxy](https://github.com/webpaladinbless/tg-ws-proxy)
- Либо выберите бесплатный MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

В большинстве случаев можно начать так:
- обновите ipset через `service.bat` и включите `Game Filter`
- если это не решит проблему, дополнительно включите `ipset any`

Учтите, что режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если результат отсутствует, создайте обсуждение в разделе [Discussions](https://github.com/webpaladinbless/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/webpaladinbless/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Добавлять адреса для обхода можно в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
