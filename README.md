> Его могут использовать как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как потенциально опасные или относящиеся к хакерским инструментам. В результате файл удаляется и отправляется в карантин. Название обнаружения при этом обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, лучше добавить исключение. При отсутствии такой уверенности рекомендуется отключить обнаружение PUA.

## ⚙️Установка и использование

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика услуг DNS, выбрав вариант, отличный от "Поставщик по умолчанию"
    * В Firefox откройте настройку "DNS через HTTPS", выберите режим "Персональный", затем нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы - [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 рекомендуется этот способ
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/webpaladinbless/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и включите "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы

5. Запустите необходимый файл
    * Для поиска подходящей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления стратегии в автозапуск используйте **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Назначение файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск через services.msc</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из служб
  - **`Check Status`** - просмотр состояния обхода и служб: стратегии автозапуска и WinDivert
  - **`Game Filter`** - изменение режима обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - переключение режима обхода для сервисов из `ipset-all.txt`.  
  Эта настройка полезна при проверке ресурса, который без zapret работает, а с ним - нет.  
  В скобках показывается текущий режим:
    - `none` - ни один IP не проходит проверку
    - `loaded` - проверяется наличие IP в списке
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включение или отключение автоматического поиска обновлений
  - **`Replace active fakes`** - замена текущего фейка на другой из каталога `bin`
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** - ручная проверка обновлений
  - **`Run Diagnostics`** - поиск распространённых причин неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного прекращения работы клиента
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не меняется

- При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться процесс winws.exe (обход).  
Если его нет, обратитесь к [#522](https://github.com/webpaladinbless/zapret-discord-youtube/issues/522)

### Рабочей стратегии нет
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося Блокнота
  - В появившейся папке найдите `hosts` и откройте его текстовым редактором от имени администратора
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте подключение. Если результат не изменился, убедитесь, что `hosts` действительно был сохранён.

#### Работа не гарантируется. Если способ не помог, используйте [версию Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/webpaladinbless/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут терять работоспособность со временем.**
> Вариант, который какое-то время работал, впоследствии может перестать работать после обнаружения.
> Здесь доступно много стратегий обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из них, изменив её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` -> `Run Diagnostics` проверьте отсутствие ошибок

- Убедитесь, что нужный адрес присутствует в списке доменов или IP-адресов

- Проверьте остальные стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- См. [#765](https://github.com/webpaladinbless/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезапустите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; при обнаружении ошибок исправьте их, затем в конце выберите Y
- Удалите старый каталог zapret
- Скачайте свежую версию (`zapret-discord-youtube-...`) со [страницы релизов](https://github.com/webpaladinbless/zapret-discord-youtube/releases)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа доступен флажок разблокировки, включите его, нажмите "Применить" и "ОК"
- Распакуйте архив в новую папку в корне диска, используя путь без пробелов и специальных символов
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если выбранная стратегия не работает, закройте программу через значок замка в панели задач и попробуйте следующую
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение не работает при включённом zapret

- Проверьте в `service.bat`, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Узнайте имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что настроен [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться
- Переберите остальные стратегии, особенно если прежняя раньше работала
- Дополнительная информация есть в [#251](https://github.com/webpaladinbless/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что активирован [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно выяснить, на какой стратегии открывается YouTube, и запустить её
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord
- Проверьте приложение Discord и выясните, помогла ли очистка кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей
- Если Discord не открывается и в браузере, повторно проверьте все стратегии. YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/webpaladinbless/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/webpaladinbless/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Начните с универсального варианта:
- через `service.bat` обновите ipset и активируйте `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Учитывайте, что режим `ipset any` может нарушить открытие множества сайтов. Не оставляйте его включённым постоянно: определите IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/webpaladinbless/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет подходящей проблемы

- Опишите её [здесь](https://github.com/webpaladinbless/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены, которые нужно исключить. Например, это пригодится, если IP-сеть есть в `ipset-all.txt`, но конкретный домен из неё фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, исключённые из обработки
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
